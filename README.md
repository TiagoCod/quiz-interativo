# 🧠 Quiz Interativo

Um projeto de quiz desenvolvido para testar conhecimentos gerais sobre Tecnologia da Informação (TI), utilizando HTML5, CSS3 e JavaScript.

O projeto conta com perguntas de múltipla escolha, validação de respostas, pontuação automática e apresentação do desempenho ao final do quiz.

## 🚀 Demonstração

🔗 **Acesse o projeto:** [Quiz Interativo]([tiagocod.github.io/quiz-interativo/](https://tiagocod.github.io/quiz-interativo/))

## ✨ Funcionalidades

- Apresentação inicial do quiz.
- Perguntas de múltipla escolha.
- Seleção e identificação de respostas corretas e incorretas.
- Navegação entre as perguntas.
- Controle de progresso.
- Contabilização automática de acertos e erros.
- Cálculo do percentual de aproveitamento.
- Exibição dos resultados ao finalizar.
- Opção para reiniciar o quiz.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação das páginas.
- **CSS3:** estilização e identidade visual.
- **JavaScript:** lógica, interatividade e manipulação do DOM.
- **LocalStorage:** armazenamento dos resultados.
- **Font Awesome:** utilização de ícones.

## 🎯 Objetivo

Este projeto foi desenvolvido com o objetivo de praticar e aprimorar conhecimentos em desenvolvimento web, especialmente na utilização de JavaScript para criação de aplicações interativas.

Também representa uma oportunidade de aplicar na prática conceitos estudados, desenvolver habilidades de programação e construir um portfólio.

## 📌 Melhorias futuras

O projeto continuará recebendo atualizações gradualmente, com novas funcionalidades e melhorias, como:

- Novas categorias de perguntas.
- Diferentes níveis de dificuldade.
- Aprimoramento da responsividade.
